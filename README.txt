사다리 게임 (PWA) — 폴드7 설치 방법
========================================

[폴더 구성]
  index.html      게임 본체
  manifest.json   앱 이름·아이콘·전체화면 설정
  sw.js           오프라인 실행용 서비스워커
  icons/          앱 아이콘

[1] 인터넷에 올리기 (Netlify Drop, 5분)
  1. PC 크롬에서 https://app.netlify.com/drop 접속
  2. 압축을 푼 "ladder-game" 폴더를 화면에 끌어다 놓기
  3. 생성된 https://○○○.netlify.app 주소 복사
     ※ 계속 쓰려면 무료 회원가입 후 사이트를 "Claim" 해야 주소가 유지됩니다.

[2] 폴드7에 설치하기
  1. 폴드7 크롬에서 위 주소 접속
  2. 우측 상단 ⋮ → "홈 화면에 추가" 또는 "앱 설치" 선택
  3. 홈 화면의 "사다리" 아이콘으로 실행 → 주소창 없는 전체화면
  4. 한 번 실행한 뒤에는 비행기 모드에서도 실행됩니다.

[3] 게임을 수정해서 다시 올릴 때
  1. 수정된 index.html로 교체
  2. sw.js 맨 위의 CACHE 버전을 올리기 (ladder-game-v1 → v2)
  3. Netlify 사이트 관리 화면 → Deploys 에 폴더를 다시 끌어다 놓기
  4. 폰에서 앱을 완전히 닫았다가 다시 열면 새 버전 적용

[알아둘 점]
  - 진동은 이 정식 주소에서 정상 작동합니다 (미리보기 화면에서는 차단됨).
  - 효과음은 미디어 음량을 따릅니다. 첫 탭 이후에 소리가 납니다.
  - 입력한 명단은 폰 안에만 저장되며 외부로 전송되지 않습니다.
